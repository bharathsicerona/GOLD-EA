How To Use
----------
1. Attach the EA to an XAUUSDm chart in MT5.
2. Open the Inputs tab.
3. Enter the values above.
4. Save them as a broker-specific preset from MT5 if you want a reusable `.set` file.

Exness Notes
------------
1. This preset is built for the exact symbol `XAUUSDm`.
2. If your account uses a different suffix, change `InpTradeSymbol` to the exact market watch symbol.
3. Session hours use broker server time, so check Exness server time before live use.
4. If spread is frequently above 500 points on your account type, increase `InpMaxSpreadPoints` slightly and retest.

When To Adjust This Preset
--------------------------
- If too many trades: raise `InpMinimumScore` to `85` or adjust `InpVolAtrThreshold`.
- If too few trades: reduce `InpMinimumScore` to `75`.
